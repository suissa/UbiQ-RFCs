# UbiQ Patent and IPR Policy (Draft)

This is a project proposal, not legal advice and not a substitute for contributor agreements or a license reviewed by counsel.

1. Contributors SHOULD disclose known patent claims necessarily infringed by implementing a contribution.
2. The project SHOULD adopt a recognized open specification policy, such as the Open Web Foundation Agreement 1.0, before promoting any RFC to Stable.
3. Until an explicit policy is adopted, contributors MUST NOT represent that this repository provides a blanket patent license or non-assertion covenant.
4. RFC text and vectors are governed by LICENSE-SPEC. Reference code is governed only by the license explicitly attached to that code.
5. Before Stable promotion, maintainers SHOULD record the selected policy, contributor acceptance mechanism, grant scope, defensive termination terms, and treatment of withdrawn contributions.

## Stable-release gate
No RFC SHOULD be promoted to Stable until the project has adopted and published a reviewed IPR policy.
